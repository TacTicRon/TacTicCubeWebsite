Free Pro Games from Ads

Players on the free version can earn the occasional free Pro game by watching short, kid-safe ads. A free Pro game lets them pick any cube size (3×3×3, 4×4×4 or 5×5×5) for one match.

How it works

  1. On the main screen, the player taps Watch Ad: Earn Points.
  2. Each ad watched all the way to the end earns 10 Ad Points. The main screen shows the total, like "Ad Points: 20/30".
  3. At 30 points (three ads), the points automatically turn into one free Pro game. The main screen then says "Bonus Pro Game Ready! (1)".
  4. On the New Match screen, the player sees "Bonus Pro Game Available!" and can choose any cube size.
  5. The free game is used up only when the match actually starts.
  • Points are only given for ads watched to the end. A skipped or closed ad earns nothing.
  • Backing out of match setup, or getting a math-game answer wrong at setup, does not use up a free game.
  • Once a match has started, the free game counts as used, even if the player quits that match early.
  • After buying Pro, the Watch Ad button goes away. Pro already includes every cube size, so free games aren't needed anymore. Any leftover points or free games simply stay saved and unused.
  • Ads, and so Ad Points, are part of the free version on iPhone and iPad.

"My child watched an ad but didn't get any points."

Suggested answer

Points are only added when an ad is watched all the way to the end. If the ad was closed or skipped early, no points are given. Please try again and let the ad finish. You'll see the Ad Points number on the main screen go up by 10.

"My child's free Pro game disappeared."

Suggested answer

A free Pro game is only used when a match actually starts. If your child backed out of setting up a match, or typed a wrong math answer during setup, the free game is still there. Check the main screen for "Bonus Pro Game Ready!". If a match did start with the free game, it was used for that match, even if the match was quit early.

"We bought Pro. What happened to our Ad Points and free games?"

Suggested answer

Nothing was lost! Pro already unlocks every cube size for every match, so free Pro games aren't needed anymore. Any leftover points and free games stay saved on your child's profile, and Pro has no ads.

"Where is the Watch Ad button?"

Suggested answer

The Watch Ad: Earn Points button is on the main screen of the free version on iPhone and iPad, near the bottom. If you've bought Pro, the button is gone because Pro has no ads and already includes everything a free game would unlock.

Nicknames

Every player picks a fun nickname. It's the name other players see. We never ask for a real name.

How it works

  • The first time a player sets up a match, the New Match screen shows "Pick a nickname:" with a box to type in.
  • The player types a nickname, then taps Save Nickname or Start Match. Either one saves it.
  • A match can't start until a nickname has been picked. If the box is empty, the player sees a friendly "Pick a nickname first!" message.
  • Nicknames don't have to be unique. Behind the scenes, every player has their own secret ID tag, so two players with the same nickname are never mixed up.
  • The nickname can be changed later in Settings.

"Why can't my child start a game?"

Suggested answer

The very first time, TacTicCube needs a nickname before a match can start. On the New Match screen, type a fun nickname in the box at the top, then tap Start Match. Please choose a made-up name, not your child's real name.

"Another player has the same nickname as my child. Is that a problem?"

Suggested answer

Not at all. Lots of players can share a nickname. TacTicCube gives every player their own secret ID tag behind the scenes, so it always knows exactly who is who.

"How do we change the nickname?"

Suggested answer

Open Settings from the main screen, change the nickname, and tap Save.

Parents can ask us to delete their child's TacTicCube data at any time.

"How do I delete my child's data?"

Suggested answer

Please fill out our Delete My Child's Data form, or email support@tacticcubegame.com. We'll take care of it promptly.
